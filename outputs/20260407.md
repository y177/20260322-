## 앱 사용법

### 사전 준비: Gemini API 키 발급

1. [Google AI Studio](https://aistudio.google.com) 접속
2. **"Get API key"** → **"Create API key"** 클릭
3. 발급된 키(`AIza...`) 복사

### 로컬 개발 환경 실행

```bash
# 저장소 클론
git clone https://github.com/y177/20260322-.git
cd 20260322-

# 패키지 설치
npm install

# Netlify CLI 설치 (최초 1회)
npm install -g netlify-cli

# 개발 서버 실행 (Netlify Functions 포함)
netlify dev
# → 브라우저에서 http://localhost:8888 접속
```

### 앱 사용 흐름

```
1. 앱 접속
   └→ API 키 설정 모달 자동 표시

2. "🔑 API 키 설정" 버튼 클릭
   └→ Gemini API 키 입력 후 저장
      (키는 브라우저 localStorage에만 저장, 서버 전송 없음)

3. 업무 유형 선택 (6가지)
   ├→ 📧 이메일 작성
   ├→ 📊 업무 보고서
   ├→ 📝 회의록 작성
   ├→ 💡 기획서 작성
   ├→ 📅 업무 일지
   └→ ✂️ 내용 요약

4. 내용 입력
   └→ 예시 버튼으로 간편 입력 가능
   └→ "⚡ AI로 생성하기" 클릭

5. 결과 확인
   ├→ "📋 복사" — 클립보드에 복사
   ├→ "💾 저장" — .txt 파일 다운로드
   ├→ "🔄 다시 생성" — 같은 유형으로 재시도
   └→ "⚡ 새 업무 시작" — 처음으로 돌아가기
```

### 지원 업무 유형 상세

| 유형 | 입력 예시 | 출력 내용 |
|------|-----------|-----------|
| **📧 이메일** | "김대리에게 내일 오전 회의 일정 확인 요청" | 격식체 이메일 전문 (수신자·본문·마무리) |
| **📊 보고서** | "3월 신규 고객 유치 현황, 목표 대비 달성률" | 개요·현황·결론·향후 계획 포함 보고서 |
| **📝 회의록** | "신제품 출시 전략 논의, 마케팅 예산 배분" | 안건·논의 내용·결정 사항·액션 아이템 |
| **💡 기획서** | "유연근무제 도입 제안" | 배경·현황 분석·제안·기대 효과·실행 계획 |
| **📅 업무 일지** | "오전 고객 미팅, 오후 보고서 작성" | 완료·미완료·특이 사항·내일 계획 |
| **✂️ 요약** | 긴 이메일/문서 붙여넣기 | 핵심 요약·주요 포인트·액션 아이템 |
